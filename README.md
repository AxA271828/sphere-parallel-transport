# 球面上矢量的平行传输与和乐性（Holonomy）

用 MATLAB 可视化一个矢量在球面纬线上做平行传输（parallel transport）时产生的和乐性：
矢量沿闭合回路传输一周后，不再回到初始方向，转过的角度恰等于回路所围球面三角形的角盈。

## 演示内容

脚本 `paralleltransport.m` 采用左右分屏的同步对比：

- **左栏（球面）**：矢量沿 45° 纬线平行传输一周，箭头端点留下红色虚线轨迹，
  直观展示传输一周后方向发生偏转。
- **右栏（圆锥展开扇形）**：将纬线所在的圆锥面沿一条母线剪开展平。
  在展开面上，平行传输退化为普通的"方向不变"平移，因此矢量始终指向同一方向；
  同时标出扇形的缺口角。

## 物理原理

沿纬度 θ₀ 的纬线传输一周，和乐角（holonomy angle）为

Δψ = 2π (1 − sin θ₀)

这正好等于圆锥展开扇形的缺口角，也等于该回路所围球冠面积的角盈
（高斯–博内定理）。对 θ₀ = 45°：

Δψ = 360° × (1 − sin 45°) ≈ 105.3°

## 使用方法

在 MATLAB 中运行：

```matlab
paralleltransport
```

脚本会弹出动画窗口，同时在当前目录生成 `parallel_transport_compare.gif`，
并在命令行输出和乐角与缺口角的数值验证。
